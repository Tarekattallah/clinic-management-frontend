A comprehensive and responsive Clinic/Hospital Management System built with React. This application provides a seamless experience for patients to book appointments, doctors to manage their schedules, and administrators to oversee clinic operations.

## ✨ Key Features

### 👨‍💼 For Patients:
- **Easy Onboarding:** Register, login, or explore the app as a Guest.
- **Find Doctors:** Browse and filter doctors by name or medical specialty.
- **Book Appointments:** Real-time appointment scheduling with selected doctors.
- **Manage Health:** View appointment history and track medical records (diagnoses & prescriptions).

### 👨‍⚕️ For Doctors:
- **Professional Profile:** Manage bio, experience, and assign specialties.
- **Schedule Management:** View upcoming, pending, and completed appointments.
- **Medical Records:** Add detailed medical notes, diagnoses, and prescriptions for patients directly from the dashboard.

### 🛡️ For Administrators:
- **Global Dashboard:** Oversee all clinic appointments and filter them by status (Pending, Confirmed, Completed, Cancelled).
- **Specialty Management:** Dynamically add or remove medical specialties from the system.

### 🎨 UI/UX Highlights:
- **Role-Based Access Control (RBAC):** Secure protected routes using React Context API based on user roles (Admin, Doctor, Patient, Guest).
- **Interactive Design:** Custom CSS animations, particle background canvas (`ParticleCanvas`), and dynamic empty states.
- **Responsive Layout:** Built with Bootstrap and custom CSS variables for a consistent experience across desktop and mobile.

---

## 🛠️ Tech Stack

- **Frontend Framework:** React.js
- **Routing:** React Router v6
- **State Management:** React Context API (`AuthContext`)
- **HTTP Client:** Axios (with interceptors for token management)
- **Styling:** CSS3 (Custom variables, Flexbox/Grid) & Bootstrap
- **Animations:** Custom HTML5 Canvas Particle System
